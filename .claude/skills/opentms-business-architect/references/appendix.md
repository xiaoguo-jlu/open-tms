## 附录B：常见业务模式参考

**现金池模式**：
```
物理池：资金实际归集到主账户
虚拟池：账户余额名义归集，资金不实际转移
ZBA：零余额账户，日终自动归集
跨境池：涉及跨境资金流动的合规管理
```

**利率基准**：
```
IBOR：LIBOR/EURIBOR/SHIBOR（逐步退出）
RFR：SOFR/EONIA/SONIA（替代基准）
央行利率：LPR/MLF/SLF（中国）
```

**套保会计模式**：
```
公允价值套保：对已确认资产/负债的套保
现金流套保：对预期交易的套保
境外套保：对境外实体的套保
```
