## 1. Open-TMS 状态色映射表

| 状态 (Status) | el-tag type | 含义 | 出现场景 |
|---------------|-------------|------|----------|
| `New` | `info` | 新建待提交 | 交易/单据创建后未提交 |
| `Draft` | `warning` | 草稿 | 暂存未提交 |
| `Submitted` | `primary` | 已提交待审批 | 审批流中 |
| `Approved` | `success` | 已审批 | 审批通过 |
| `Rejected` | `danger` | 已驳回 | 审批驳回 |
| `Executing` | `warning` | 执行中 | 交易执行中 |
| `Executed` | `success` | 已执行 | 交易完成 |
| `Settled` | `success` | 已结算 | 结算完成 |
| `Canceled` | `danger` | 已取消 | 用户取消 |
| `Closed` | `info` | 已关闭 | 流程关闭 |
| `Active` | `success` | 启用中 | 基础数据 |
| `Disabled` | `info` | 禁用 | 基础数据 |

## 6. 业界对标要点

### 6.1 FIS Quantum
- **列表密度**: 紧凑表格,单屏 15+ 行
- **录入**: 模式徽章 + 联动下拉 + 快捷键
- **状态**: 颜色统一 (绿/黄/红/蓝)
- **审批**: 弹窗 + 操作历史可见

### 6.2 Murex MX.3
- **录入**: 5 步内完成核心操作
- **联动**: 币种对 → 自动填币种;管理主体 → 默认账户
- **详情**: TopBar + 关键信息 + 主信息 + Tabs
- **批量**: 多选 + 批量审批/取消

### 6.3 SAP TRM
- **字段一致性**: 全局字段命名统一
- **状态机**: 显式状态流 + 颜色
- **审计**: 操作日志 + 审批轨迹

### 6.4 Bloomberg AIM
- **快捷键**: Ctrl+F5 刷新 / Enter 提交 / Esc 关闭
- **键盘**: 主要操作可纯键盘完成
- **多窗口**: 支持多窗口并行录入

## 7. 按钮位置约定

| 场景 | 按钮位置 |
|------|----------|
| 列表页操作列 | 右侧,3 个以内,「更多」下拉 |
| 详情页 TopBar | 右上,按状态显示 |
| 弹窗底部 | 右下,取消(左) / 确认(右,主色) |
| 审批弹窗 | 底部:驳回(左) / 拒绝(中) / 通过(右,主色) |
| 表单底部 | 右下:取消(左) / 保存(右,主色) / 提交并审批(可选) |

## 8. 错误提示规范

```javascript
// 正确:用户可见
ElMessage.error('保存失败: ' + err.message)
ElMessage.success('保存成功')
ElMessage.warning('请检查必填项')
ElMessageBox.confirm('确定删除吗?', '提示', { type: 'warning' })

// 错误:仅 console
console.error(err)  // 仅用于调试日志,必须同时 ElMessage
```

## 9. 字段格式规范

| 字段类型 | 显示格式 | 示例 |
|----------|----------|------|
| 金额 | 千分位 + 2 位小数 + 等宽 | `1,234,567.89` |
| 汇率 | 8 位小数 | `7.12345678` |
| 利率 | 4 位小数 + % | `3.8500%` |
| 时间 | YYYY-MM-DD HH:mm:ss | `2026-07-05 14:30:00` |
| 日期 | YYYY-MM-DD | `2026-07-05` |
| 编号 | 等宽字体 | `AC20260705-0001` |
