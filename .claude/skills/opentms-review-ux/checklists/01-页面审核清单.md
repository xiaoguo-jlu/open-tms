# Open-TMS UX 页面审核清单 (Checklist 01)

> 配合 `opentms-review-ux` SKILL.md 使用。审核员按此清单逐项勾选。

---

## A. 列表页审核 (e.g. AcDealList.vue / CountryList.vue)

### A1. 搜索区
- [ ] 至少有 1 个搜索字段(编号 / 名称 / 编码)
- [ ] 至少有 2 个高级筛选字段(状态 / 类型 / 时间范围)
- [ ] 支持模糊查询 + 精确筛选
- [ ] 搜索按钮 + 重置按钮齐全
- [ ] 搜索有防抖(300ms)或点击触发

### A2. 工具栏
- [ ] 新增按钮(主色,右上)
- [ ] 批量操作按钮(删除 / 审批 / 导出),多选可用
- [ ] 列设置 / 导出按钮(可选)
- [ ] 刷新按钮(可选)

### A3. 表格
- [ ] 列顺序合理(关键信息在前)
- [ ] 列宽合适,不出现挤压
- [ ] 状态列用 el-tag + 颜色统一
- [ ] 操作列在右侧,不超过 3 个,多余放「更多」下拉
- [ ] 金额右对齐,千分位显示
- [ ] 时间格式 YYYY-MM-DD HH:mm:ss
- [ ] 空数据显示 el-empty

### A4. 分页
- [ ] el-pagination 显示
- [ ] 支持 size 切换(10/20/50/100)
- [ ] 默认 size=10
- [ ] 总数显示

### A5. 视觉
- [ ] 1080p 可见 ≥10 行
- [ ] row-padding 适中(不浮夸)
- [ ] 选中行高亮

---

## B. 表单页审核 (新建 / 编辑 / 复制)

### B1. 顶部
- [ ] ModeBadge 显示(create/copy/edit/view)
- [ ] 标题清晰(新建 xxx / 编辑 xxx [编号])
- [ ] 关闭按钮(X)可关闭并提示

### B2. 主表单
- [ ] 分组清晰(基础信息 / 业务信息 / 财务信息)
- [ ] 必填项标红 *
- [ ] 校验提示友好(blur 时触发)
- [ ] 联动逻辑完整(币种对、管理主体、账户等)

### B3. 底部操作
- [ ] 保存 / 提交 / 取消 按钮齐全
- [ ] 保存按钮 loading,防重复提交
- [ ] 保存成功 ElMessage.success,跳转列表
- [ ] 失败 ElMessage.error 并保留表单数据

### B4. 状态处理
- [ ] Loading: v-loading / skeleton
- [ ] 错误: 重试按钮 + 错误说明
- [ ] 草稿保存: 浏览器关闭不丢

---

## C. 详情页审核

### C1. TopBar
- [ ] 返回按钮(左上)
- [ ] 关键操作按钮(编辑 / 删除 / 提交 / 审批 / 执行)按状态显示
- [ ] ModeBadge 显示 view 模式

### C2. 关键信息卡
- [ ] 编号 / 名称 / 状态 / 业务类型 / 创建时间 / 创建人
- [ ] 金额字段大字号 + 等宽数字
- [ ] 状态徽章颜色统一

### C3. 主信息区
- [ ] 完整展示所有字段(只读模式)
- [ ] 标签清晰分组

### C4. Tabs
- [ ] 子信息 / 操作 / 审批 / 日志 / 现金流 等 Tab
- [ ] Tab 切换不丢数据
- [ ] 默认 Tab 为第一个

### C5. 操作日志
- [ ] 按时间倒序
- [ ] 显示操作人 / 操作类型 / 操作时间 / 备注

---

## D. 弹窗审核 (审批 / 录入 / 提示)

### D1. 标题与按钮
- [ ] 标题清晰(审批 xxx / 录入 xxx)
- [ ] 底部按钮顺序:取消(左)/ 确认(右,主色)
- [ ] Esc 关闭弹窗

### D2. 表单
- [ ] 必填项标红 *
- [ ] 校验提示
- [ ] Loading 状态

### D3. 反馈
- [ ] 成功 ElMessage.success + 关闭弹窗
- [ ] 失败 ElMessage.error + 保留弹窗

---

## E. 公共组件复用

- [ ] BaseDataPicker 用于所有引用基础数据的下拉
- [ ] ModeBadge 用于所有模式标识
- [ ] FormContainer 用于所有表单容器
- [ ] ActionApprovalDialog 用于所有审批弹窗
- [ ] StatusTag 用于所有状态标签

---

## F. 跨页面一致性

- [ ] 与同模块其他页面视觉一致
- [ ] 与项目内同类型页面(如 AcDealList)交互一致
- [ ] 按钮位置一致(列表页 / 详情页 / 弹窗)
- [ ] 错误提示文案统一(不允许自定义错误样式)

---

## G. 业界对标 (P2)

- [ ] 操作步骤 ≤5 步(Murex / FIS)
- [ ] 1080p 一屏核心信息可见
- [ ] 支持快捷键 (Ctrl+F5 / Enter / Esc)
- [ ] 列表密度 (≥10 行/屏)
- [ ] 联动录入 (币种对 / 管理主体 / 账户)
- [ ] 无障碍 (a11y / 键盘 Tab / aria-label)
- [ ] 响应式 (1920 / 1440 / 1280)

---
