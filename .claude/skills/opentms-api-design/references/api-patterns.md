# API 设计业界优秀实践

## RESTful API设计原则

1. **资源导向**: URL代表资源，使用复数名词，嵌套资源表达关系。
2. **统一接口**: 使用标准HTTP方法，无状态交互，统一响应结构。
3. **错误处理**: 使用适当的HTTP状态码，响应体包含错误详情，错误码需业务语义化。
4. **分页与过滤**: 默认分页避免全量返回，支持排序和多条件筛选。

## 金融系统接口特殊要求

- **精度处理**: 金额 DECIMAL(18,2)，汇率 DECIMAL(18,8)，利率 DECIMAL(10,4)。
- **日期时间**: ISO 8601格式，明确时区（推荐UTC）。
- **状态机设计**: 状态流转明确，变更需审计日志，非法转换返回明确错误。
- **幂等性**: 所有写操作接口支持幂等，使用 idempotencyKey 防重复提交。
