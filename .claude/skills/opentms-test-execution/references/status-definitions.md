# 测试执行与缺陷状态定义

> 从 SKILL.md 附录A、附录B合并移出。

## 测试执行状态

| 状态 | 英文 | 含义 |
|------|------|------|
| 待执行 | Pending | 还未执行 |
| 执行中 | In Progress | 正在执行 |
| 通过 | Pass | 测试通过 |
| 失败 | Fail | 测试失败 |
| 阻塞 | Block | 无法执行 |
| 跳过 | Skip | 跳过不执行 |

## 缺陷状态

| 状态 | 英文 | 含义 |
|------|------|------|
| 待修复 | Open | 新建缺陷，待修复 |
| 修复中 | In Progress | 正在修复 |
| 待验证 | Verification | 已修复，待验证 |
| 已关闭 | Closed | 验证通过，缺陷关闭 |
| 不予处理 | Won't Fix | 确认不修复 |
