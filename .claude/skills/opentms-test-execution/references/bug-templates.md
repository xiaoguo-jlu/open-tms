# 常见缺陷模板

> 从 SKILL.md 附录D移出。

## 资金精度问题

```markdown
### 缺陷描述
金额计算精度丢失

### 复现步骤
1. 进入交易录入页面
2. 输入金额 100.99
3. 保存交易

### 预期
金额应保持100.99

### 实际
金额显示为100或101
```

## 数据校验问题

```markdown
### 缺陷描述
必填字段未校验

### 复现步骤
1. 进入新增页面
2. 不填写必填字段
3. 点击保存

### 预期
提示"XXX为必填字段"

### 实际
保存成功或提示不明显
```

## 状态流转问题

```markdown
### 缺陷描述
状态流转异常

### 复现步骤
1. 创建一笔交易
2. 审批通过
3. 执行交易

### 预期
状态从PENDING→APPROVED→EXECUTED

### 实际
状态跳跃或状态不变
```
