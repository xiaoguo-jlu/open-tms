# 进度跟踪模板

## 5.1 特性级进度看板

将以下模板贴在Feature Issue的body中，每完成一个阶段更新状态：

```markdown
## 🎯 {特性名称} - 全流程进度

### 基本信息
| 项目 | 内容 |
|------|------|
| 模块 | {所属模块} |
| 目标版本 | M1-x |
| 优先级 | P0/P1/P2 |
| PM | {负责人} |
| UX | {负责人} |
| Dev | {负责人} |
| QA | {负责人} |

### 阶段进度
| 阶段 | 状态 | 开始日 | 完成日 | 产出物 | 评审人 |
|------|------|--------|--------|--------|--------|
| PM设计 | ✅ 已完成 | MM-DD | MM-DD | [PRD](链接) | PM-Lead |
| UX设计 | ✅ 已完成 | MM-DD | MM-DD | [原型](链接) | PM-Lead |
| 表结构设计 | ⬜ 进行中 | MM-DD | - | [DDL](链接) | TA |
| 接口设计 | ⬜ 待开始 | - | - | [API](链接) | TA |
| 后端开发 | ⬜ 待开始 | - | - | [代码](链接) | BE |
| 前端开发 | ⬜ 待开始 | - | - | [代码](链接) | FE |

| 测试执行 | ⬜ 待开始 | - | - | [报告](链接) | QA |

### 缺陷列表
| 编号 | 描述 | 严重程度 | 状态 |
|------|------|----------|------|
| - | - | - | - |

### 风险与阻塞
| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| - | - | - |
```

## 5.2 阶段状态定义

| 状态 | 标识 | 含义 |
|------|------|------|
| 待开始 | ⬜ | 尚未开始，前置依赖还未满足 |
| 进行中 | 🔄 | 正在执行中 |
| 已完成 | ✅ | 已完成并通过质量门禁 |
| 已阻塞 | 🔴 | 因外部依赖无法继续 |
| 已跳过 | ⏭️ | 本特性不需要此阶段 |
