## 前端开发服务管理

**目录**: `web/`

**功能**:
- 启动/停止前端 Vite 开发服务器
- 生产构建

**使用方法**:
```bash
cd web

# 启动开发服务器 (http://localhost:3000)
npm run dev

# 生产构建
npm run build

# 安装依赖
npm install
```

**依赖**:
- Node.js 和 npm
- `web/` 目录下执行

**端口**: 3000 (默认)
