# 数据库设计业界优秀实践

> 从 SKILL.md 第五节移出。

## 数据库设计原则

1. **规范化设计**: 满足第三范式（3NF），避免数据冗余，确保数据完整性。
2. **性能优先**: 高频查询字段建立索引，避免过度规范化（反范式化），考虑读写分离。
3. **可扩展性**: 字段预留扩展空间，编码字段使用VARCHAR，避免硬编码。
4. **安全性**: 敏感数据加密存储，审计字段完整，权限控制。

## 金融系统数据库特殊要求

- **金额/利率/汇率**: 精度 DECIMAL(38,18)，必须有 CHECK 约束，避免 FLOAT/DOUBLE。
- **日期时间**: 业务日期用 DATE，业务时间用 TIMESTAMP，推荐 UTC 时区。
- **状态字段**: 使用 CHAR(1) 明确枚举值，命名用 status 而非 state。
- **交易表**: 幂等键（唯一业务编码），状态机控制，审计日志。
