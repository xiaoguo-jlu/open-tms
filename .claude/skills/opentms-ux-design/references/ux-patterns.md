## 企业级TMS界面设计原则

1. **数据密度与可读性平衡**: 企业级用户需要查看大量数据，界面应保持高数据密度，通过分组、折叠等方式组织信息。
2. **操作效率优先**: 支持键盘快捷键、批量操作、默认值和常用选项置顶。
3. **状态反馈清晰**: 每个操作都有明确的状态反馈（加载中、成功、失败）。
4. **一致性原则**: 同类功能保持一致的交互模式、视觉风格、术语表述。
5. **容错设计**: 操作前确认、支持撤销操作、防止误操作的二次确认。

## 组件设计模式

### 列表页模式
- 工具栏：搜索 + 筛选 + 操作按钮
- 表格：可配置列、排序、分页
- 底部：状态汇总、分页导航

### 表单页模式
- 分类组织：基本信息 + 扩展信息
- 分组展示：减少单页字段数量
- 即时校验：字段级错误提示

### 详情页模式
- 头部：关键信息和状态
- 主体：详细信息（可折叠分组）
- 底部：操作日志
