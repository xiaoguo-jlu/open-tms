# AT 交易列表 优化需求

**创建日期**: 2026-07-07
**优先级**: P1
**状态**: 待评审
**所属模块**: dealing
**关联页面**: /dealing/at-deal

---

## 需求总览

AT 交易(账户转账 / Account Transfer)列表页存在 **3 项 P1 体验问题**,核心矛盾是筛选区与表格列均严重不足,导致用户无法在列表上完成日常查询与操作,必须频繁进入详情才能看到关键金额信息。优化后将显著降低交易员在"列表-详情"之间的来回跳转成本。

## P1 - 必须优化

### AT-1: 筛选字段不足

**问题描述**
当前筛选区仅 3 个字段:交易编号、转账类型、状态。比对 AC/FX 列表,AT 列表筛选项缺失最严重,无法支持账户维度的精确定位,而账户恰恰是 AT 业务的核心维度。

**当前截图位置**: /tmp/at-deal-list-before.png
**用户影响**
- 无法按"源账户/目标账户"过滤(这对 AT 业务而言是核心维度)
- 无法按"起止日期"做时间窗口查询
- 无法按"交易员"查看个人工作量
- 无法按"支付方式"区分电汇/票汇/内部转账

**验收标准**
1. 筛选区至少支持 6-8 个字段:交易编号、转账类型、源账户、目标账户、状态、交易员、起止日期(创建时间)、支付方式
2. 账户字段应使用 `<el-select>` 下拉选择账户(显示账户编号 + 账户名),而非输入框
3. 日期范围筛选支持快捷日期(今日 / 本周 / 本月 / 本季度 / 自定义)
4. 筛选条件持久化到 URL query

**预估工作量**: M

---

### AT-2: 表格列字段缺失

**问题描述**
当前表格仅有 5 列,大量关键信息缺失,用户在列表页看不到核心金额与日期信息,每次都必须点击进入详情页才能确认。

**当前截图位置**: /tmp/at-deal-list-before.png
**缺失的关键列**:
- 源金额(Source Amount)
- 目标金额(Target Amount)
- 汇率(Exchange Rate,跨币种时必填)
- 起息日(Value Date)
- 支付方式(Payment Method)
- 状态(Status)
- 交易员(Trader)
- 操作(Actions)

**用户影响**
- 风控复核时无法在列表上看清"源币种/目标币种/汇率",每次都要点进详情
- 资金计划岗无法按起息日扫描当日到期交易
- 财务无法按状态批量导出

**验收标准**
1. 表格至少包含以下列:交易编号、转账类型、源账户、目标账户、源金额、目标金额、汇率、起息日、支付方式、状态、交易员、操作
2. 源金额 / 目标金额 / 汇率右对齐,千分位分隔,汇率保留 4-6 位小数
3. 跨币种转账时,汇率列高亮显示
4. 起息日列支持按日期排序
5. 在 1440px 分辨率下所有列可见(或操作列固定右侧后其余列横向滚动)

**预估工作量**: M

---

### AT-3: 表头列被裁切,"操作"列不可见

**问题描述**
"操作"列未设置 `fixed="right"`,在 1280px 以下屏幕或浏览器窗口缩放时被自动裁切。同时表头列本身过多导致整体列宽被压缩,关键字段名被截断显示。

**当前截图位置**: /tmp/at-deal-list-before.png
**用户影响**
- 用户无法对单条 AT 交易执行"审批/编辑/删除"等基本操作
- 列表沦为"只读视图",违背金融系统对操作效率的高要求

**验收标准**
1. 操作列固定右侧,设置 `fixed="right"`,宽度 160-200px
2. 表头各列宽合理,字段名不被截断(可通过 `show-overflow-tooltip` 兜底)
3. 至少包含:查看详情、编辑(草稿态)、审批(待审批态)、复制、删除(草稿态)
4. 操作按钮根据状态动态显隐

**预估工作量**: S
