## 五、修复的 Bug(开发-测试 迭代)

### BUG_001 getOne() NullPointerException

**问题**: `generateRuleNumber()` 调用 `getOne(...).getRuleNumber()` 当无匹配时 NPE  
**修复**: 增加 null 检查,跳过 `.getRuleNumber()`  
**修复版本**: v1.1

### BUG_002 JSONB 字段类型不匹配

**问题**: MyBatis-Plus `insert` 将 `old_value`/`new_value` 当 VARCHAR,PostgreSQL 报 JSONB 类型错误  
**修复**: 改用 `JdbcTemplate.update` 显式 CAST `?::jsonb`  
**修复版本**: v1.1

### BUG_003 MyBatis-Plus @Version 报错

**问题**: `updateById` 报 `MP_OPTLOCK_VERSION_ORIGINAL not found`  
**修复**: 改用 `JdbcTemplate.update` + 手动 `version=version+1`  
**修复版本**: v1.1

### BUG_004 响应数据未刷新

**问题**: `updateRule` 返回 `getById(id)` 时拿到旧数据(MyBatis-Plus 缓存)  
**修复**: 改用 `JdbcTemplate.queryForObject` 直接读  
**修复版本**: v1.1

### BUG_005 Active 唯一约束 NULL 处理

**问题**: PostgreSQL 默认 NULL DISTINCT,允许多个 NULL 重复  
**修复**: 改用 `NULLS NOT DISTINCT` 部分索引  
**修复版本**: v1.1

### BUG_006 Redis 依赖不可用

**问题**: basedata 模块无 spring-data-redis 依赖  
**修复**: 用 `ConcurrentHashMap` 内存缓存代替(降级方案)  
**修复版本**: v1.1
