## 设计过程记录

### 2026-07-08 - M1-默认银行账户规则 UX 原型 v1.1

**完成内容**:
- ✅ 5 个核心页面全部 HTML 化:
  - 规则列表页(搜索/筛选/批量/行内编辑/状态切换/分页)
  - 新增/编辑表单(5 维选择器 + 默认账户联动 + lock banner + 校验提示)
  - 详情页(只读 + Tabs:基本信息/审计历史/使用统计)
  - FX 录入联动演示(★ v1.1 双方向 + 防抖可视化 + 无匹配兜底)
  - match 调试工具(/test-match 端点可视化 + 算法步骤展示)
- ✅ 状态覆盖演示:加载中(loading)/ 数据为空 / 错误态(500 + 409 Conflict)
- ✅ 设计规范遵循:Element Plus 风格 + Open-TMS 配色(#1E40AF 主色)
- ✅ 浮动导航 + section 锚点跳转

**遇到的问题**:
- 5 个页面如果独立文件难以维护 → 解决方案:单文件 HTML,内嵌 CSS/JS,section 锚点跳转
- 双方向账户字段的视觉表达 → 解决方案:左右并排"Inflow 收账 + Outflow 付账",分别标注命中的规则编号
- 防抖 300ms 的可视化 → 解决方案:用 ⏱/💾 标签指示"防抖中"和"Redis 缓存命中"
- 审计历史展示 → 解决方案:用 Timeline 组件,CREATE/UPDATE/DISABLE 用颜色和图标区分

**设计决策**:
- **表格密度**:参考 FIS Quantum 高密度风格,每行 11 列(规则编号/对手方/金融产品/方向/币种/默认账户/优先级/状态/生效日/操作)
- **行内编辑**:优先级和状态支持行内快速编辑,无需进入详情页
- **Active 唯一约束的提示**:编辑表单内嵌"已校验通过 ✓"绿色提示,降低用户焦虑
- **FX 录入联动演示**:单独一节完整演示,便于 FE 开发对齐 match 调用语义
- **match 调试工具**:作为"运营端点"的独立页面,提供完整命中规则列表 + 算法步骤

**待确认事项**:
- 删除确认对话框的具体样式(当前用 alert-warning 演示)
- 复制规则是否需要"复制为新规则"还是"复制为草稿"
- 批量操作的交互(勾选行 → 工具栏按钮)
- 移动端适配(本期不做,但 layout 应支持响应式断点)
