## 设计过程记录

### 2026-05-26 - 资金管理主体UX设计
**完成内容**:
- M1-资金管理主体UX原型 - 3个页面
  - 资金管理主体列表页（左右分栏布局）
  - 新增/编辑主体抽屉（折叠分组表单）
  - 主体详情页（Tab展示）

**遇到的问题**:
- 资金管理主体字段较多（基础+监管+会计+税务） → 采用折叠分组减少首屏信息密度
- 组织层级与列表联动 → 采用左侧组织树 + 右侧列表的经典设计

**设计决策**:
- 列表页采用左右分栏：左侧组织树筛选，右侧列表展示
- 表单采用折叠分组：基础信息默认展开，监管/会计税务默认折叠
- 详情页采用Tab分类：基本信息/监管信息/会计准则/税务配置/关联信息

**待确认事项**:
- [ ] 组织树的展示深度是否需要限制
- [ ] 关联信息Tab的展示内容是否完整
