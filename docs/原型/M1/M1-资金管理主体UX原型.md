## 五、交互流程

### 5.1 新增主体流程
1. 用户点击 [+ 新增] 按钮
2. 抽屉从右侧滑入，遮罩层出现
3. 用户填写基础信息（必填项）
4. 可展开"监管信息"和"会计税务"补充信息
5. 点击 [保存] → 校验必填项 → 保存成功 → 抽屉关闭 → 列表刷新
6. 点击 [取消] 或 ✕ → 确认弹窗 → 关闭抽屉

### 5.2 删除主体流程
1. 用户点击 🗑️ 删除按钮
2. 弹出确认弹窗："删除后不可恢复，确认删除【集团母公司】？"
3. 系统校验：是否存在下级主体/关联银行账户/关联交易
4. 若存在关联 → 弹窗提示："该主体存在关联数据，无法删除"
5. 若无关联 → 删除成功 → 列表刷新

### 5.3 层级筛选流程
1. 用户点击左侧组织树节点
2. 列表自动筛选：该主体及其所有下级主体
3. 树节点高亮显示选中状态
